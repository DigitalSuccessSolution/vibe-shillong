# Two Neon Events — Landing Page

A responsive React + Tailwind CSS (Vite) landing page based on the supplied 20-page KED / F Lounge event proposal.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Notes before launch
- Event date and timings follow the proposal: Saturday, 12 December 2026; Kids Neon Event 12 PM–7:30 PM; Adult Neon Nights 8 PM onwards.
- Kids family pass is shown as a proposed ₹1,000–₹1,200 range, not a final price.
- Adult normal pass is shown as ₹1,499. VIP ₹1,999 is labelled proposed and the proposal also flags an unresolved ₹1,399 approval query.
- Venue address, ticketing URL, contact details, final prices, VIP benefits, refund terms, and final complimentary-entry policy were not provided in the PDF.
- The registration form is front-end demo only. Connect it to an API, CRM, or ticketing platform before production.
- Images are loaded from Unsplash URLs; replace with approved event/venue photography before publishing.
